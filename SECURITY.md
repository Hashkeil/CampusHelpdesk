# Security reporting

This is an academic project. Report suspected vulnerabilities privately to the repository maintainers using GitHub private vulnerability reporting if enabled. Do not publish passwords, tokens, private tickets or exploit results containing other users' data.

Include the affected commit, a minimal reproduction using test accounts, expected and actual behavior, and the impact. Avoid service-disruption testing on shared or public infrastructure.

The controls and current limitations are documented in `docs/SECURITY-CONTROLS.md`.
